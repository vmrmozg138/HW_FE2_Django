# Проект "Закомство с Django"

## Описание
Вданном проекте были применены базовые навыки, полученные в уроке "Знакомство с Django". По сути созданы 2 страницы и настроены маршрутизации в приложении.

## Расположение проекта
Забрать проект себе можно если выполнить команду 
`git clone https://github.com/vmrmozg138/HW_FE2_Django.git`

## Описание проекта
* приложение, реализованное в проекте, называется catalog
* реализованы 2 страницы (home.html и contacts.html)
* настроена маршрутизация
* также реализован контроллер для обработки post-запроса на странице contacts
